# Trackpad Control v1.2.2

This release restores gesture feedback across macOS Spaces and updates Cycle
Windows for current Mission Control behavior.

## Highlights

- **Reliable gesture overlay:** each presentation receives a fresh overlay window
  attached to the active Space, fixing invisible traces and Desktop 1-only behavior.
- **Native Cycle Windows selection:** cycling now hovers Mission Control thumbnails,
  shows the standard blue selection border, and selects the highlighted window when
  the gesture ends. It no longer raises underlying windows while Mission Control is open.
- **Predictable direction and ordering:** thumbnails follow their visual left-to-right
  order, swipe direction is preserved, and steps generated while Mission Control opens
  are coalesced instead of skipping the first visible selection.
- **Smoother response:** the cycle interval is reduced from 0.32 seconds to 0.18 seconds,
  movement is retained during the cooldown, and straight swipes tolerate minor sensor jitter.
- **New identity:** a new trackpad-based app icon and matching active/inactive menu-bar
  glyphs provide a consistent identity at app and status-item sizes.

## Download and install

1. Download `trackpad_control-v1.2.2.zip` below.
2. Unzip it and drag `trackpad_control.app` to Applications.
3. On first launch, right-click the app and choose **Open**, then confirm **Open**.
4. Allow Accessibility and Automation permissions when macOS requests them.

Requires macOS 26.4 or newer on Apple Silicon.

The optional `starter-gestures.json` asset contains the starter gesture library.
Import it from **Settings → Advanced → Import…**. Importing replaces the current
gesture list, so export existing gestures first if you want to preserve them.
